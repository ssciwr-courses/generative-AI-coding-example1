# Generative AI for writing research software

This is the repository that contains the data and starter files for example 1 in the course.

## Instructions

1. Create a new Python source file in `src` and name it `analyze_data.py`
2. In this file, create a function that reads in the data file `expec.t` from the `data` folder.
3. Verify that it reads in the data correctly.
4. Create a test that tests the reading functionality using pytest. Ask Copilot where to place the file and how to name it. Ask Copilot to run the tests for you and also to explain to you how to run the tests.
